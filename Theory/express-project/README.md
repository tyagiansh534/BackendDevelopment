## 1. Overview
A clean, modular **Express.js** starter boilerplate demonstrating:
- JSON request parsing (`express.json()`).
- Custom logging middleware.
- RESTful endpoints (`GET /api/items`, `POST /api/items`).
- Centralized error-handling middleware.

---

## 2. How to Run
```bash
cd "Theory/express-project"
npm install
node app.js
```
Open `http://localhost:3000/` in browser or Postman.
