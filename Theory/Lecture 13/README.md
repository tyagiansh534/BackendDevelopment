## 1. Overview
This module explores foundational database engineering:
- **Relational SQL Database:** PostgreSQL student management database with normalized tables, foreign keys, and analytical joins (`student_management.sql`).
- **Document NoSQL Database:** MongoDB equivalent schema with embedded arrays, indexing, and aggregation pipelines (`mongodb_students.js`).
- **Theoretical Comparison:** In-depth trade-off analysis between SQL and NoSQL architectures (`sql-vs-mongodb.md`).
- **PostgreSQL Reference:** CLI cheat sheet and query guide (`postgresql-quick-reference.md`).
