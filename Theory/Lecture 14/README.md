## 1. Overview
This module demonstrates rigorous relational schema modeling and normal form decomposition:
1. **Library Management Schema (`library_schema.sql`):** Fully constrained relational design with publishers, authors, books, members, and loan transactions.
2. **Entity-Relationship Architecture (`library_er_diagram.md`):** Conceptual entity relationships and cardinalities.
3. **Hands-on Normalization (`normalized_orders.sql`):** Step-by-step resolution of raw unnormalized orders through 1NF, 2NF, and 3NF.
4. **Theory Documentation (`order_normalization.md`):** Complete guide on functional dependencies and anomaly prevention.
