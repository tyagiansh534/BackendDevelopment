## 1. Overview
This module explores NoSQL document schema design, Mongoose ORM models, and strict validation:
- **Task 1: Data Modeling (`Task1_Data_Modeling/`):** Trade-off analysis between Embedded vs Referenced document patterns.
- **Task 2: E-Commerce Modeling (`Task2_Ecommerce_Model/`):** Hybrid schema architecture balancing read performance with normalization.
- **Task 3: Mongoose Blog System (`Task3_Mongoose_Blog/`):** Full Mongoose schema with timestamps, virtual properties, and embedded comments.
- **Task 4: Data Validation (`Task4_Data_Validation/`):** Custom validators, regex matching, numeric bounds, and enum constraints.
