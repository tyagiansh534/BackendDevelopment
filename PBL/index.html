Project-Based Learning (PBL): Production Microservices

Author: Ansh Tyagi | SAP ID: 590014867

Docker Compose FastAPI Replicas Nginx Load Balancing 10/10 Tests Passed

1. Overview

A production-ready microservice deployment containerizing a FastAPI Student Management application, scaled horizontally across two container replicas (fastapi-node-1 and fastapi-node-2) fronted by an Nginx Reverse Proxy / Load Balancer.

2. Multi-Container Topology

  • Nginx Load Balancer (Port 8080): Distributes incoming traffic across backend replicas via round-robin.
  • FastAPI Node 1 (Port 8001 → 8000): Primary replica.
  • FastAPI Node 2 (Port 8002 → 8000): Secondary replica.
  • Automated Test Suite: 10 automated test cases asserting SAP ID, endpoints, headers, and CRUD.

3. How to Run with Docker Compose

cd PBL
docker compose up -d --build

# Run automated tests:
py automationTesting.py http://127.0.0.1:8080

Access the live load balancer at http://localhost:8080/.
