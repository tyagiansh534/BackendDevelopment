# Experiment 13 - A: Express.js & MongoDB / Mongoose User Management System

**Course:** Backend Development Laboratory (CSFS3008P)  
**Author:** Ansh Tyagi  
**SAP ID:** 590014867  

---

## 1. Objective
To connect a Node.js/Express.js backend to a MongoDB database using the Mongoose ODM, design user schemas, and implement full user registration and authentication workflows.

## 2. Features
- MongoDB database connection handling via Mongoose.
- User schema definition with validation rules.
- RESTful routes for user registration, login, and profile lookup.

## 3. How to Run
```bash
npm install
node server.js
```
