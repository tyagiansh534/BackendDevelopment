Experiment 13-A: MongoDB & Mongoose User System

Author: Ansh Tyagi | SAP ID: 590014867 | Course: Backend Development Laboratory

Node.js MongoDB Mongoose ODM Authentication

1. Objective

To connect an Express.js application to a MongoDB database using the Mongoose Object Data Modeling (ODM) library, design schema models with validation, and build user registration and authentication endpoints.

2. Architecture & Components

  • Connection Management: Robust asynchronous connection handler with error catching.
  • User Schema: Validation for unique emails, trimmed usernames, and hashed passwords.
  • Registration & Login: REST endpoints validating payload credentials and returning JSON responses.

3. How to Run Locally

cd "Lab/experiment 13 a"
npm install
node server.js

Ensure a local MongoDB daemon (mongod) or MongoDB Atlas URI is configured.
