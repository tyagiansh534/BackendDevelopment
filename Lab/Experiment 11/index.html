Experiment 11: Asynchronous Architecture

This web application combines modern HTML5, CSS3, JavaScript (ES6+), and AJAX to demonstrate a decoupled single-page application model:

  • Decoupled Presentation & Data: The frontend layout renders instantly while data payloads (JSON and XML) are loaded over HTTP without page refreshes.
  • Dual Format Support: Demonstrates real-time switching between native JSON deserialization (`response.json()`) and XML Document Object traversal (`DOMParser`).
  • Client-Side Processing: In-memory filtering and multi-criteria searching without redundant network overhead.
  • Graceful Error Handling: Intercepts network disruptions, HTTP 404/500 errors, and provides user feedback alerts.
