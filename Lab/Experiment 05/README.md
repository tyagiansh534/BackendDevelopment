## 1. Objective
To understand and implement fundamental JavaScript building blocks essential for web application logic and backend services:
1. Initialize, access, mutate, and traverse **Arrays**.
2. Create and manipulate **Objects** (key-value pairs, dynamic properties, dot vs bracket notation).
3. Author modular, reusable **Functions** for business logic.
4. Build a **Problem-Based Learning (PBL)** in-memory Library Management Utility performing CRUD operations on structured collections.

## 2. Directory Structure


---

## 3. How to Run

### Option 1: Via Node.js Terminal
Run the scripts directly using Node.js:
```bash
# Task 1
node script.js

# Task 2
node script2.js

# PBL Library Utility
node library.js
```

### Option 2: Via Web Browser / Live Server
1. Open `index.html` in your browser (or right-click in VS Code and select **Open with Live Server**).
2. Click the interactive buttons to execute tasks and observe outputs in both the styled UI and browser DevTools console (**F12**).
3. Test the interactive Library Manager by adding new books and searching by title.
