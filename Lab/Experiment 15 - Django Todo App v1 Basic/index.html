Experiment 15: Django To-Do Application (MVT Architecture)

Author: Ansh Tyagi | SAP ID: 590014867 | Course: Backend Development Laboratory

Python 3.12 Django MVT SQLite ORM Django Admin

1. Objective

To develop a full-featured, database-driven To-Do Application using Python's Django web framework (Model-View-Template pattern), ORM migrations, and built-in Admin dashboard.

2. Architecture & Components

  • Model (todo/models.py): Task model with title, completion boolean, and timestamp.
  • Views (todo/views.py): Listing, adding, toggling completion, and deleting tasks.
  • Templates (todo/templates/todo/): Base layout inheritance and modular navbar partials.
  • Admin Dashboard: Custom search fields and filters for tasks at /admin/.

3. How to Run Locally

cd "Lab/Experiment 15 - Django Todo App v1 Basic"
py manage.py makemigrations
py manage.py migrate
py manage.py runserver

Visit http://127.0.0.1:8000/ in your browser.
