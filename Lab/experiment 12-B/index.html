Experiment 12-B: State Management (Cookies & Sessions)

Author: Ansh Tyagi | SAP ID: 590014867 | Course: Backend Development Laboratory

State Management express-session cookie-parser HTTP Statelessness

1. Objective

HTTP is a stateless protocol where each request is processed independently. This experiment demonstrates two fundamental server-side persistence techniques to track users across requests:

  • Server-Side Sessions using express-session (storing state securely on server with session IDs in cookies).
  • Client-Side Cookies using cookie-parser (instructing client browsers to store key-value attributes).

2. Demonstrations Included

  • Session Example (session-example.js): Tracks and increments a page view counter on every page refresh; provides a /destroy endpoint to safely end the session.
  • Cookie Example (cookie-example.js): Sets secure cookies (/set-cookie), reads incoming cookie headers (/get-cookie), and clears cookies (/clear-cookie).

3. How to Run Locally

cd "Lab/experiment 12-B"
npm install

# Test Sessions:
node session-example.js
# Visit http://localhost:3000/ to see view count increase

# Test Cookies:
node cookie-example.js
# Visit http://localhost:3000/set-cookie then http://localhost:3000/get-cookie
