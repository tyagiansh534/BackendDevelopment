Experiment 13-B: Express + Mongoose User Registration & Todo API

Author: Ansh Tyagi | SAP ID: 590014867 | Course: Backend Development Laboratory

JWT Auth Bcrypt Hashing MongoDB Relations Mongoose ODM

1. Objective

Build a secure, production-patterned user authentication and relational task management backend with Express.js, Mongoose, and JSON Web Tokens (JWT).

2. API Endpoints Table

MethodEndpointAuth RequiredDescription
POST/api/auth/registerNoRegisters user and hashes password with bcrypt.
POST/api/auth/loginNoAuthenticates credentials and returns 7-day JWT.
GET/api/todosYes (JWT)Retrieves logged-in user's todos.
POST/api/todosYes (JWT)Creates new todo linked to user ID.
PUT/api/todos/:idYes (JWT)Updates todo title, completion, priority.
DELETE/api/todos/:idYes (JWT)Removes owned todo document.

3. How to Run Locally

cd "Lab/Experiment 13 B - Express Mongoose Todo App"
npm install
npm start

Server starts at http://localhost:3000.
