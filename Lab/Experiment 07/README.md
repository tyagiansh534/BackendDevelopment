# Experiment 07: Programs to Familiarise ES6 Concepts

**Course:** Backend Development  
**Author:** Ansh Tyagi  
**SAP ID:** 590014867  

---

## 1. Objective
To understand and apply **ES6 (ECMAScript 2015)** features in modern JavaScript development.

---

## 2. Directory Structure

```
Experiment 07/
├── 01_let_const.js                  # Block-scoped variables vs function-scoped var
├── 02_arrow_functions.js            # Arrow syntax & lexical this
├── 03_template_literals.js          # String interpolation & multiline strings
├── 04_destructuring.js              # Array and object destructuring
├── 05_spread_rest.js                # Spread operator (...) & Rest parameters
├── 06_default_parameters.js         # Default parameter values
├── 07_classes.js                    # ES6 Classes, constructor & inheritance
├── 08_modules/                      # ES Modules (import / export)
│   ├── math.js                      # Named exports
│   ├── main.js                      # Import demo
│   ├── package.json                 # "type": "module" configuration
│   └── index.html                   # Browser module demo
├── 09_promises_async_await.js       # Asynchronous JavaScript with Promises & Async/Await
├── 10_enhanced_object_literals.js   # Shorthand properties and methods
└── index.html                       # Interactive browser runner for all ES6 concepts
```

---

## 3. How to Run

### Via Node.js Terminal
Run each script directly using `node`:
```bash
node 01_let_const.js
node 02_arrow_functions.js
node 03_template_literals.js
node 04_destructuring.js
node 05_spread_rest.js
node 06_default_parameters.js
node 07_classes.js
node 08_modules/main.js
node 09_promises_async_await.js
node 10_enhanced_object_literals.js
```

### Via Browser
Open `index.html` in any browser or with Live Server to run and inspect demonstrations interactively.
