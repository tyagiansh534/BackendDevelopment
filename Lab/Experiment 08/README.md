## 1. Objective
To learn and demonstrate **DOM (Document Object Model) manipulation** and **event handling**, and build an interactive practical web application.

## 3. How to Run

### Via Browser / Live Server
1. Open `index.html` in your web browser (or right-click in VS Code and select **Open with Live Server**).
2. Use the navigation links to explore:
   - **DOM Manipulation:** Element selection, style modification, dynamic creation & traversal.
   - **Event Handling:** Event listeners, bubbling, capturing, and delegation.
   - **Interactive To-Do List App:** Complete practical application integrating ES6, DOM, and event handling.
