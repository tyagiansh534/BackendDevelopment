# Experiment 12 - A: Express.js MVC Web Application with EJS View Templating

**Course:** Backend Development Laboratory (CSFS3008P)  
**Author:** Ansh Tyagi  
**SAP ID:** 590014867  

---

## 1. Objective
To familiarize with server-side scripting using Node.js, npm, Express.js, nodemon, and EJS dynamic view templating.

## 2. Features
- Multi-route Express application (`/`, `/users`, `/profile`, `/register`, `/results`, `/timetable`).
- Dynamic server-side rendering using Embedded JavaScript (`EJS`) templates.
- Parameter handling and request body parsing.

## 3. How to Run
```bash
npm install
node app.js
```
Open `http://localhost:3000/` in your browser.
