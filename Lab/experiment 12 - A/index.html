Experiment 12-A: Express.js MVC & EJS Templating

Author: Ansh Tyagi | SAP ID: 590014867 | Course: Backend Development Laboratory

Node.js Express.js EJS Templates MVC Pattern

1. Objective

To implement server-side web scripting using Node.js and Express.js with EJS (Embedded JavaScript) templating. Demonstrates the Model-View-Controller pattern, dynamic view rendering, route handling, and partials reuse.

2. Key Routes & Features Implemented

  • GET / — Home landing page rendered with header and footer partials.
  • GET /users — Lists all registered users dynamically passed to the EJS view.
  • GET /profile/:id — Dynamic route parameter handling rendering student details.
  • GET /register & POST /register — User registration form with URL-encoded body parsing.
  • GET /timetable & GET /results — Academic semester timetable and grade report views.

3. Application Structure

experiment 12 - A/
├── app.js             # Main Express server and route controller
├── package.json       # Dependencies (express, ejs, nodemon)
├── public/            # Static stylesheets and assets
│   └── css/style.css
└── views/             # EJS Template files
    ├── partials/      # Header, navbar, and footer components
    │   ├── header.ejs
    │   └── footer.ejs
    ├── index.ejs
    ├── users.ejs
    ├── profile.ejs
    └── register.ejs

4. How to Run Locally

# Navigate to directory
cd "Lab/experiment 12 - A"

# Install dependencies
npm install

# Start server
node app.js

Open http://localhost:3000/ in your browser to view the application.
