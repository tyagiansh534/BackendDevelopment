Lab Evaluation 01: Eisenhower Matrix Todo App (PostgreSQL)

Author: Ansh Tyagi | SAP ID: 590014867 | Course: Backend Development Laboratory

PostgreSQL Node.js / Express EJS Templates Glassmorphism UI

1. Overview

A full-stack, server-side rendered Task Management Web Application organizing tasks into the 4 quadrants of the Eisenhower Matrix based on Urgency and Importance using PostgreSQL.

2. Eisenhower Matrix Quadrants

  • Q1: Do First (Urgent & Important): Critical crises and deadlines.
  • Q2: Schedule (Not Urgent & Important): Strategic planning and development.
  • Q3: Delegate (Urgent & Not Important): Interruptions and delegate-ready requests.
  • Q4: Drop (Not Urgent & Not Important): Time-wasting distractions.

3. Bonus Features Implemented

  • Dynamic Category Filter: Filter by Work, Personal, Study tags.
  • Live Search Bar: Real-time keyword filtering across task titles and descriptions.
  • Live Quadrant Feedback: Checkbox toggles dynamically display target quadrant.

4. How to Run Locally

cd "Lab/Lab Evaluation 01"
npm install
node app.js

Open http://localhost:3000/ in your browser.
