## 2. Key Topics Covered
1. **Serverless Architecture (FaaS)**:
   - Event-driven execution model
   - Ephemeral compute containers
   - Pay-per-use billing vs idle server costs
2. **AWS Lambda vs Cloud Run Functions**:
   - Cold start latency and concurrency scaling
   - Container portability and image-based execution
   - Integration with cloud services (S3/DynamoDB vs Cloud Storage/Firestore)
3. **Architectural Trade-offs & Recommendations**:
   - Multi-cloud portability
   - Developer productivity and deployment speed
